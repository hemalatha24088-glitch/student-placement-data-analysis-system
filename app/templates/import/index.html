Automated Validation Rules

  • Roll Number Uniqueness: Existing roll numbers are rejected to prevent record collisions.
  • Foreign Key Integrity: Placements must match an existing student roll number in the database. New companies are automatically registered.
  • Package Range: CTC amounts must be positive numbers between 0.50 LPA and 200.00 LPA.
  • Duplicate Offer Rule: Duplicate entries for the exact same student, company, and role in a given year are caught and reported.
  • Error Transparency: Invalid rows are never silently dropped; line-by-line feedback is provided.
